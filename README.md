# MapUp - Analytics Dashboard Assessment

## Features

- **Data Visualization**: Visualize EV population data using charts and graphs such as bar charts and pie charts.
- **Responsive UI**: The dashboard is designed to be responsive, ensuring optimal display across different screen sizes (desktop, tablet, and mobile).
- **Top Counties**: Displays the counties with the highest number of electric vehicles.
- **EV Type Distribution**: Visual representation of the distribution of different types of electric vehicles.
- **Yearly EV Distribution**: An interactive chart showing the growth of electric vehicles year by year.

## Tech Stack

- **Frontend**: React.js, Material UI, Recharts
- **Data Parsing**: CSV Parsing

## Project Structure

- **/src/components**: Contains React components for rendering charts and graphs.
- **/src/assets/images**: Contains static assets like images and logos.
- **/src/utils**: Utility functions for handling CSV data parsing and other helper functions.
- **/public**: Contains csv file.

## Steps :
- **Clone the Repository** : https://github.com/TamannaBagwan/mapup-analytics-dashboard-assessment
- **Navigate to Project Directory** : cd ev-dashboard
- **Install Dependencies** : Install the required dependencies using npm : npm install or yarn install
- **Run the Application** : npm start or yarn start
- Open http://localhost:3000 with your browser to see the result.
